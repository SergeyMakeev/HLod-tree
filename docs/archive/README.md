# Frontier documentation archive

Everything in this directory is historical. It may describe APIs, data
layouts, performance characteristics, or build procedures that are no longer
current. Use [the current documentation index](../README.md) for integration
and capacity planning.

## Performance engineering journals

The [performance archive](performance/README.md) preserves the ten optimization
campaign journals, including hypotheses, experiments, rejected changes,
paired measurements, and old-version comparisons. The journals are retained
as engineering evidence rather than current product documentation.

Raw historical benchmark artifacts remain under the repository's
`bench_results/` directory.
